# Nebuloid Speed Typing Battle

A React + Tailwind CSS typing-race game with 10 progressively harder levels and a downloadable certificate after every completed level.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Logo

Put the Nebuloid logo at:

`public/logo.png`

The game uses that file automatically in the header and certificate.

## Notes

The level sentences are based on public information from Nebuloid Tech Studio's website. The game does not require an API or backend.
