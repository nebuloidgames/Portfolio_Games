# Stack Master

React + Vite + Tailwind CSS game.

## Run
1. Extract the ZIP.
2. Open the project folder in terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local Vite URL.

## Features
- Player name before gameplay
- 10 levels
- Moving blocks
- Real horizontal overlap/cropping
- Score and combo
- Game over + retry
- Dynamic certificate after every completed level
- Keyboard: Space / Enter
