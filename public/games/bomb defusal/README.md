# Bomb Defusal — React + Tailwind

A complete 10-level logical bomb-defusal game built with React, Vite and Tailwind CSS.

## Features

- Landing page
- Name entry
- 10 unique deterministic logic puzzles
- Countdown timer per level
- Score system
- Game Over / Retry
- Per-level certificate
- Certificate download as PNG
- Next Level
- Final master certificate
- Play Again
- Responsive dark tactical UI
- Sound toggle UI
- No external game assets required

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The production build will be generated in `dist/`.
