# Catch the Brand

React + Tailwind CSS game.

## Setup

```bash
npm install
npm run dev
```

Put the Nebuloid Tech logo at:

```text
public/logo.png
```

## Game flow

Start Level → Player Name → Level Gameplay → Certificate → Next Level

There are 5 levels. Correct targets give +10 points. Missing a correct target or catching a wrong target costs a life.
